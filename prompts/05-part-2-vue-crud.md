# Prompt 05: Part 2 Vue CRUD interface

> Extend the Vue frontend so every booking CRUD action is available through the interface. Accept hotel names or cities in search, let a selected demo traveler book a listed stay, show joined booking history and an empty state, retain cancelled rows with a cancelled status, and permanently remove deleted rows. Make Cancel and Delete visibly distinct, and use an in-page deletion confirmation instead of JavaScript alert, confirm, or prompt dialogs.

Outcome: added demo-traveler selection, result-table booking, complete booking history, status feedback, distinct cancellation and deletion controls, and inline permanent-delete confirmation while preserving the original results headings.
